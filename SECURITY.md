# Política de segurança

## Relato de vulnerabilidades

Não abra uma Issue pública contendo senhas, chaves, documentos fiscais ou outros dados sensíveis.

Caso encontre uma vulnerabilidade, entre em contato com o mantenedor pelo perfil do GitHub e informe:

- parte afetada;
- forma segura de reproduzir;
- impacto observado;
- sugestão de correção, se houver.

## Boas práticas

- Use apenas credenciais locais e variáveis de ambiente.
- Mantenha dependências atualizadas.
- Revise arquivos antes de fazer commit.
- Utilize dados fictícios em exemplos e demonstrações.
