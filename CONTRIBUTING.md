# Como contribuir

Obrigado pelo interesse no projeto.

1. Crie uma branch a partir da `main`.
2. Faça alterações pequenas e bem descritas.
3. Nunca inclua senhas, chaves de API ou dados reais.
4. Execute os testes ou a compilação antes de enviar.
5. Abra um Pull Request explicando problema, solução e validação.

## Padrão de commits

Use mensagens curtas e objetivas, por exemplo:

- `Corrige validação de dados`
- `Adiciona sensor de luminosidade`
- `Melhora documentação de instalação`
